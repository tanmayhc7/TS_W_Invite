# Tanmay & Shalome — Wedding Invitation

Interactive wedding invitation website for Tanmay & Shalome.

## Files
- `index.html` — main invitation page
- `assets/opening-video.mp4` — opening animation (H.264)
- `assets/opening-video.webm` — WebM fallback

## GitHub Pages
Upload the entire folder contents to the root of your GitHub repository, keeping the `assets` folder beside `index.html`.
Then enable GitHub Pages from **Settings → Pages → Deploy from a branch**.

Do not move or rename the files unless you also update the paths in `index.html`.
